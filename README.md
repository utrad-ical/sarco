# サルコペニア解析ツール

このリポジトリは、体幹部CT画像からサルコペニア解析を行うためのツールです。[CIRCUS](https://circus-project.net/) のCADプラグインとして使用されることを想定しています。

## 機能

*   **自動的な筋肉領域のセグメンテーション:** U-Netベースの深層学習モデルを利用して、CT画像から骨格筋領域を自動的にセグメンテーションします。
*   **定量的な解析:** サルコペニアに関連する以下の指標を計算します。
    *   骨格筋面積 (SMA)
    *   平均骨格筋密度 (MSMD)
    *   内臓脂肪面積 (VAT)
    *   皮下脂肪面積 (SAT)
*   **CIRCUSとの連携:** CIRCUSのCADプラグインとして動作し、解析結果を分かりやすく表示します。

## 動作の仕組み

解析プロセスは、主に2つのステップで構成されています。

1.  **セグメンテーション:** `sarcosegmentation.py` スクリプトが、事前学習済みのU-Netモデルを用いて、入力されたCT画像から筋肉領域を特定し、セグメンテーションします。
2.  **計算:** `sarcocalculate.py` スクリプトが、セグメンテーションされた筋肉領域と元のCT画像を用いて、サルコペニア関連指標を計算します。

計算された指標や生成された画像などの結果は、CIRCUSのインターフェース上に表示されます。

## 使い方

このツールは、CIRCUSプラグインとして実行されることを意図しています。このリポジトリの `Dockerfile` を用いて、必要な依存関係と解析スクリプトを含むDockerイメージをビルドすることができます。

CIRCUSのインターフェースからプラグインを起動すると、`processsingle.sh` スクリプトが実行され、単一のケースに対して解析が行われます。

## スクリプト

*   `bin/sarcosegmentation.py`: U-Netモデルを用いて筋肉のセグメンテーションを実行します。
*   `bin/sarcocalculate.py`: セグメンテーション結果からサルコペニア指標を計算します。
*   `processsingle.sh`: 単一ケースの解析プロセスを統括するメインスクリプトです。
*   `Dockerfile`: プラグインのDockerイメージをビルドするために使用します。
*   `plugin.json`: CIRCUSプラグインの設定と表示方法を定義します。

## 学習データの扱い

学習時（`--mode train`）は、`--labelused` のラベルが1画素もない症例を自動で除外し、除外した症例のラベルファイルを表示します（`readfiles.drop_empty_labels`）。空のラベルのまま学習すると、lumbarmodifier と sarcosegmentation は0番スライスを正解として空のラベルで学習してしまうためです。推論時は除外しません。

## 内臓領域マスク

`sarcosegmentation.py` は、結果ラベル `<名前>_<L1|L3>.result.nii.gz` と並べて内臓領域マスク `<名前>_<L1|L3>.visceral.nii.gz` を出力し、`__result_<L1|L3>.csv` の `{<L1|L3>_visceral_path}` 列にそのファイル名を記録します（`sarcocalculate.visceral_mask`）。

*   マスクは、筋肉（ラベル1）に囲まれた領域（`get_visceral_region`）から、筋肉と椎体（ラベル2、3）を除いたものです。筋肉が最も多いスライス1枚だけに値1が入ります。椎弓・脊柱管は椎体ラベルに含まれないので、マスクに残ります。
*   画像の幾何情報（原点・画素間隔・向き）は元の体積と同じです。`tricolor<i>.nii.gz` にも幾何情報を付けるようにしました。
*   既存の結果から作り直すには `bin/tools/make_visceral_masks.py` を使います。GPUも再セグメンテーションも不要です。列 `gray`, `label`, `name` を持つCSVを渡すと、マスク、確認用PNG（CT・筋肉の輪郭が赤・椎体が青・内臓領域が緑）、各症例の確認用の数値を書いた `manifest.csv` を出力します。`muscle_coverage`（筋肉の中心から見て筋肉がある方向の割合）が低い症例は、筋肉の輪が途切れているので確認してください。

## 前処理のキャッシュ

体積の読み込み、リサンプル、腕の除去は時間がかかり、しかも同じ処理が何度も繰り返されます（L1とL3で同じ体積を処理する、学習のたびに同じ症例を前処理する、など）。そこで `lumbar.py`、`lumbarmodifier.py`、`sarcosegmentation.py` は、`--cache_dir` を指定すると症例ごとの前処理結果を保存し、次回以降はそれを使います（`bin/prepcache.py`）。

*   キャッシュの対象: lumbar の投影像（体積全体ぶん。データ拡張のずらしは行の切り出しで再現）、modifier の探索範囲、segmentation の対象スライス、計算段の体幹マスク。
*   キャッシュのキーは、入力ファイルのパス・サイズ・更新日時（`.mhd` はデータファイルも含む）と前処理の設定です。どれかが変われば作り直すので、古い結果が使われることはありません（古いファイルは残るだけです）。
*   結果はキャッシュなしの場合とビット単位で同じです。
*   シェルスクリプトは、推論では `$TEMPDIR/cache`、学習では `./train_temp/cache` を使います。環境変数 `SARCO_CACHE_DIR` で場所を変えられます。Docker では `/temp` は実行ごとに消えるので、実行をまたいで再利用したい場合は永続ボリュームを指定してください。
*   前処理のコードを変更して出力が変わる場合は、`bin/prepcache.py` の `CACHE_VERSIONS` の該当する番号を上げてください。

## Dockerイメージのビルド

Dockerイメージをビルドするには、リポジトリのルートディレクトリで以下のコマンドを実行します。

```bash
docker build -t sarcopenia-plugin .
```
